实现一个完全离线的沙箱能力检查服务。输入是模拟进程、资源和逻辑句柄，资源固定拥有租户、版本与 read/write/list 权限。进程和句柄各有创建代数，传递只能缩减能力集合，父链保存确切代数与授权时窗；处于规则互相收紧的多个沙箱时，每个沙箱都必须允许。句柄号允许回收重用，子句柄支持多代传递。进程重启、资源重建、沙箱收紧及撤回父句柄都可能使后代失效，同样的旧代不因重新授予而复活。

用 SQLite 记录能力关系及模拟 I/O 审计结果。支持一次受保护的多资源操作，至少一种模式要求所有资源满足后才写一条模拟业务收据。预检快照允许脱离事务，使用时必须沿祖先链重查每条授权、资源代数、会话代数和当前时钟；失败不得写部分 I/O。重复消费 ID 必须返回第一次已提交结果，不复算历史权限。

用独立进程固定传递、父句柄撤销、同号重建、读写交换与消费交错；在模拟 I/O 写入未提交与事务结束未应答两处终止自建测试进程。覆盖曾授权的祖先再发同权、两个代数同句柄号、多资源有一项撤权、并行读者一直看到完整提交。报告每次判定的阻断祖先和确切代数，用独立能力模型核对结果。

在 Windows 原生 Python 3.12、标准库和 CPU 环境下实现，全部输入自行合成，离线测试。交付源码、README、可重放 cases.json 和自动化测试。提供 python -m solution --input cases.json --output result.json 与 python -m unittest discover -s tests -v。测试须断言具体结果，README 写明规则、输入输出、错误码和实测结果。
